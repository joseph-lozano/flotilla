    Keyboard shortcuts

    Everything in Flotilla is a keystroke away. On Linux, Ctrl takes the place of ⌘.

    Anywhere in the app

    These work wherever you are in the app.

    MacLinuxWhat it does
    ⌘NCtrl+NNew thread
    ⌘KCtrl+KSearch threads, messages and commands
    ⌘1 to ⌘9Ctrl+1 to 9Open the first to ninth thread in the sidebar
    ⇧⌘], ⇧⌘[Ctrl+Shift+], [Next and previous thread
    ⇧⌘SCtrl+Shift+SArchive the open thread and open the next
    ⌘ZCtrl+ZUndo an archive, for 5 seconds after it
    ⌃⌘SF9Show or hide the sidebar
    ⌘RCtrl+RSync now, from boat.dev
    ⌘,Ctrl+,Settings
    ⌘WCtrl+WClose the window
    ⌘QCtrl+QQuit

    Writing a message

    In the message box, and on New thread.

    KeysWhat it does
    EnterSend, or steer while a turn runs. On New thread, start the thread and open it.
    ⌘EnterOn New thread, start the thread and stay, to start another.
    ⇧EnterA new line.
    ↑, ↓In an empty message box, bring back earlier prompts, and go forward again.
    /, $, @Open the menu of skills and commands, Codex's skills, or files. See Slash commands, skills and @-mentions.
    ↑, ↓, Enter or Tab, EscIn those menus: move, pick, close.

    In search

    In the search box that ⌘K opens.

    KeysWhat it does
    ↑, ↓Move through the results.
    EnterOpen the thread or message, or run the command.
    > firstShow only commands.
    EscClear what you typed, then close.

    With the pointer

    A few things are quicker with the pointer.

    • Double-click a thread's row or its title to rename it.
    • Right-click a row for the thread's menu, and a message for Copy and Cite.
    • ⇧-click models in the model list to start one prompt on several.
    • Press and hold Hold to merge until it fills.

    On the Mac, most of these are also in the menu bar, under Flotilla, View and Thread. Linux has no menu bar: search (Ctrl+K) lists every command, with its shortcut.
