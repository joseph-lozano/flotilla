# Keyboard shortcuts

Everything in Flotilla is a keystroke away. On Linux, Ctrl takes the place of ⌘.

## Anywhere in the app

These work wherever you are in the app.

| Mac | Linux | What it does |
| --- | --- | --- |
| ⌘N | Ctrl+N | New thread |
| ⌘K | Ctrl+K | Search threads, messages and commands |
| ⌘1 to ⌘9 | Ctrl+1 to 9 | Open the first to ninth thread in the sidebar |
| ⇧⌘], ⇧⌘[ | Ctrl+Shift+], [ | Next and previous thread |
| ⇧⌘S | Ctrl+Shift+S | Archive the open thread and open the next |
| ⌘Z | Ctrl+Z | Undo an archive, for 5 seconds after it |
| ⌃⌘S | F9 | Show or hide the sidebar |
| ⌘R | Ctrl+R | Sync now, from boat.dev |
| ⌘, | Ctrl+, | Settings |
| ⌘W | Ctrl+W | Close the window |
| ⌘Q | Ctrl+Q | Quit |

## Writing a message

In the message box, and on New thread.

| Keys | What it does |
| --- | --- |
| Enter | Send, or steer while a turn runs. On New thread, start the thread and open it. |
| ⌘Enter | On New thread, start the thread and stay, to start another. |
| ⇧Enter | A new line. |
| ↑, ↓ | In an empty message box, bring back earlier prompts, and go forward again. |
| /, $, @ | Open the menu of skills and commands, Codex's skills, or files. See [Slash commands, skills and @-mentions](threads.md#slash-commands-skills-and--mentions). |
| ↑, ↓, Enter or Tab, Esc | In those menus: move, pick, close. |

## In search

In the search box that ⌘K opens.

| Keys | What it does |
| --- | --- |
| ↑, ↓ | Move through the results. |
| Enter | Open the thread or message, or run the command. |
| > first | Show only commands. |
| Esc | Clear what you typed, then close. |

## With the pointer

A few things are quicker with the pointer.

- Double-click a thread's row or its title to rename it.
- Right-click a row for the thread's menu, and a message for Copy and Cite.
- ⇧-click models in the model list to start one prompt on several.
- Press and hold **Hold to merge** until it fills.

On the Mac, most of these are also in the menu bar, under **Flotilla**, **View** and **Thread**. Linux has no menu bar: search (Ctrl+K) lists every command, with its shortcut.
